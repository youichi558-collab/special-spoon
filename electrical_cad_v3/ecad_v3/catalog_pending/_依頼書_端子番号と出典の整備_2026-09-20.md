## 1. 絶対厳守（既存の指示書から継続）

1. **価格データを一切含めない。** カタログに価格ページがあっても使わない
2. **生カンマ禁止。** 区切りに使う以外のカンマを欄の中に入れない（「・」「/」を使う）
   - **例外は端子番号欄だけ**。ここはカンマで端子を区切る（後述）
   - **どうしても備考にカンマが要る場合は、その欄を `"` で囲うこと。**
     2026-09-20にDriveから取り込んだ8ファイルは、備考に
     `【端子番号】電源側=奇数(1,3,5)/負荷側=偶数(2,4,6)` のような生カンマが入っていて
     **8列のはずが12列に割れていた**。取り込み時にこちらで `"` 囲いに直した。
3. **推測しない。** 確定できない値は空欄にし、**備考に理由を書く**
4. **出典を明記する**（9列目）。加えて**カタログURL**（10列目）を入れる
5. Pythonの `csv` モジュールで読み書きし、**保存後に読み直して列数を検証**する

## 3. やること（3つ）

### 【A】端子番号をグループ形式にする（対象234件）

**いまの問題**：部品DBの端子番号は「1台ぶんの全端子」の平打ちで、
展開接続図では1台が複数のシンボル（コイル／主接点／補助接点）に分かれて
描かれるため、そのままではシンボルに割り当てられない。

**書き方**：

```
コイル:A1,A2 / 主接点:1,3,5,2,4,6 / 補助:13,14
```

- グループ名と端子は `:` で区切る
- **グループ間は `/`**
- グループ内の端子は `,` で区切る

**【重要】端子記号そのものに `/` が入る部品がある**（三菱インバータの
`R/L1` `S/L2` `T/L3` `P/+` `N/-` など）。
CAD側は「**`/` の直後に『グループ名:』が続くときだけ区切りとみなす**」ように
してあるので、`主回路:R/L1,S/L2` は正しく読める。**端子記号のスラッシュを
消したり置き換えたりしないこと。**

**グループ名**：基本は **`コイル` / `主接点` / `補助`** の3つ。
CAD側は「コイル」「主」「補助」を含むかで判定するので、`操作コイル`
`主回路` `補助接点` のような揺れは吸収される。
3つで足りない部品（タイマの瞬時接点・限時接点、インバータの制御端子など）は
**実態に合わせて足してよい**（例：`主回路` `制御入力` `周波数設定` `出力`
`セーフティ`）。

**主回路端子の表記**：**数字側（`1,3,5 / 2,4,6`）に統一する**（盛田さん判断）。
カタログが `L1,L2,L3 / T1,T2,T3` や `1L1,3L2,5L3 / 2T1,4T2,6T3` で書かれていても
数字側へ揃える。IECは `1/L1` のように併記するので、どちらも同じ端子を指す。
**ただし数字側の記載がカタログに無い場合は勝手に変換せず、カタログどおりに
書いて備考に「カタログは記号表記のみ」と残すこと。**

**埋めること**：
- **コイル端子が入っていない行が150件ある**（`A1,A2` が無い）
- **接点構成があるのに補助接点の端子番号が無い行が85件ある**
  （例：`S-T10` は接点`1a`なのに端子欄に `13,14` が無い）
- カタログで確定できない場合は**空のままにして、備考に理由を書く**

### 【B】端子番号でないものを備考へ移す（対象57件）

端子番号欄に**端子番号でない説明文**が入っている行がある。ほぼキーエンスのPLCユニット。

```
KV-B16XC   → 脱着式端子台16点
KV-C32XC   → コネクタ(MIL規格)32点
KV-XD02    → RJ-45 8極モジュラコネクタ×2PORT
```

このままだと**図面の端子に「脱着式端子台16点」と印字される**。

- **端子番号欄を空にし、この文言は備考へ移す**
- 実際の端子番号が取れるなら入れる（取れなければ空のまま）

### 【C】出典（9列目）とカタログURL（10列目）を全635件に入れる

**現状、出典が入っている行は0件。**
（三菱インバータの30行だけ10列。残り605行は8列）

- **出典**：人が読む短文。例 `三菱電磁開閉器 p.41`
- **カタログURL**：そのページのDriveファイルURL
  （`https://drive.google.com/file/d/<fileId>/view`）

**ページ単位に分割済みのカタログは、そのページのファイルを指すこと。**

| メーカー | 分割 | 件数 |
|---|---|---|
| 三菱電機 | 済 | 504 |

**未分割の107件は総合カタログへのリンクでよい**（分割はしない＝盛田さん判断）。
ページは出典テキストのページ番号で追う。

**【罠】ページ番号とファイル名がズレるカタログがある。**

- 三菱電磁開閉器：`file43.pdf` が**印刷 p.41**（+2オフセット）

目視確認せずに過去メモのオフセットを鵜呑みにしないこと。**

## 6. 完了の確認

作業後、以下を機械で検査してから報告すること。

```python
import csv, glob, re

# 端子ラベルとして許すのは英数字と / + - . だけ。
# 「日本語が入っていないか」だけでは `RJ-45(10BASE-T/100BASE-TX)` のような
# 説明文を取りこぼす（実際に1件あった）ので、ホワイトリストで判定する。
TOKEN = re.compile(r'[A-Za-z0-9/\+\-\.]+')
# 「標準価格は本CSVに含めていません」のような宣言文を誤検出しないよう、
# 数字を伴う「円」だけを価格とみなす
PRICE = re.compile(r'[0-9０-９][,，0-9０-９]*\s*円')

def term_tokens(cell):
    """端子番号欄から、グループ名(「名前:」)を除いた端子トークンだけを返す。
    グループ名は日本語で正しいので、それを説明文と誤検出しないために要る。"""
    out = []
    for part in re.split(r'/(?=\s*[^/:：,]+[:：])', cell or ''):
        body = re.sub(r'^\s*[^:：]+[:：]', '', part)
        out += [x.strip() for x in body.split(',') if x.strip()]
    return out

for f in glob.glob('*.csv'):
    for i, r in enumerate(csv.reader(open(f, encoding='utf-8')), 1):
        assert len(r) >= 8, (f, i, '列数不足＝カンマ混入の疑い')
        assert not PRICE.search(','.join(r)), (f, i, '価格情報')
        assert all(TOKEN.fullmatch(t) for t in term_tokens(r[5])), (f, i, '端子欄に説明文')
```

**この検査は作業前のデータに対して実際に動かしてある。**
2026-09-20時点で「端子欄に説明文」が**57件**、他は0件。
**作業後は57件も0件になるのが完了条件。**

- 【A】【B】【C】それぞれの対応件数
- **確定できず空のままにした件数と、その理由の内訳**
