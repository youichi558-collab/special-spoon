部品DBファイル未設定

1つの型式が複数のシンボルに分かれる部品（コイル＋主接点、ブレーカ本体＋補助接点等）は
「名前:番号,番号 / 名前:番号,番号」の形で書くと、割り当て時にどれを使うか選べます。
例) コイル:A1,A2 / 主回路:1,3,5,2,4,6 / 補助:13,14
「:」を使わず従来どおり「A1,A2,1,2」と書いた場合はそのまま1つの並びとして扱います。

カタログDBから探す

Google Drive上のカタログDB(メーカー別CSV)から型番を検索し、選んだものだけを部品DBに追加します。
カタログDBが未設定・未導入でもCADは通常通り使えます（この欄が使えなくなるだけです）。

フォルダが選択されていません

Drive上の「カタログDB」フォルダを選ぶと、中のCSVをまとめて取り込みます。
次回以降は選び直し不要です（Driveの内容を更新したら「再取込」を押してください）。

保留CSVを読み込む

Claudeとの会話でカタログを読み取ってもらいpushしてもらった「登録待ちCSV」を、 コピペ無しでそのまま読み込みます。内容はCSV一括登録欄に入りますが、 「CSVから一括登録」ボタンを押すまでは実際には登録されません。

CSV一括登録

1行1部品、カンマ区切り。ヘッダー行は任意（maker等の文字を含む行は自動でスキップ）。
形式: メーカー,型番,種別,定格電圧,定格電流,端子番号,接点構成,備考
種別は次のいずれか:
breaker(ブレーカ) / contactor(電磁接触器) / starter(電磁開閉器(サーマル一体)) / thermal(サーマルリレー) / coil(リレーコイル) / timer(タイマ) / pb(押ボタン) / pb_lamp(照光押ボタン) / pb_estop(非常停止) / selector(セレクタ) / selector_key(鍵付セレクタ) / selector_lamp(照光セレクタ) / selector_pb(セレクタ押ボタン) / lever(モノレバー) / contact_unit(コンタクトユニット) / lamp(ランプ・表示灯) / inverter(インバータ) / servo(サーボアンプ) / servo_motor(サーボモータ) / motor(モーター) / plc(PLC(シーケンサ)) / plc_unit(PLC増設ユニット) / hmi(タッチパネル・表示器) / terminal(端子台) / fuse(ヒューズ) / transformer(トランス) / option(増設ユニット等(付属品))
例: 三菱電機,S-T21,contactor,AC200V,21A,"A1,A2,1,3,5,2,4,6",a3b1,
