カタログ型式検索（ローカルPDF）

catalog_config.json に登録したカタログPDF/フォルダから型式を検索します。表の形式はカタログによって「フレームが列（三菱タイプ）」と「フレームが行のかたまり（富士タイプ）」の2種類あるので、見た目に合わせて選んでください。

🗑

索引(インデックス)はCADの画面からではなく、ecad_v3フォルダ内の「インデックス作成.bat」を ダブルクリックして作成・更新してください(登録済みの全カタログをまとめて処理します)。 作っておくと検索が大幅に速くなります。

CSV一括登録

1行1部品、カンマ区切り。ヘッダー行は任意（maker等の文字を含む行は自動でスキップ）。
形式: メーカー,型番,種別,定格電圧,定格電流,端子番号,接点構成,備考
種別は次のいずれか: coil(リレーコイル) / sw_no(a接点) / sw_nc(b接点) / breaker(ブレーカ) / motor(モーター) / terminal(端子台) / lamp(ランプ) / fuse(ヒューズ) / transformer(トランス)
例: 三菱電機,S-T21,coil,AC200V,21A,"A1,A2,1,3,5,2,4,6",a3b1,
